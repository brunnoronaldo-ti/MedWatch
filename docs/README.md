# Docs folder

## How is the folder docs?

This folder is called "docs", is used to store information about the project, kind of record the project. The folder have a three sub-folders, their are:

- *Decisions*: To store all decisions made in the project, one example is me explaining "what language I should use?";
- *Ideas*: To record all ideas that I can do in the future, like a new implementation, feature or research;
- *Research*: In this folder, I record the all research that I was do for the creation of the project.
